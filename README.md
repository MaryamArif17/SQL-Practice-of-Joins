# SQL Joins Practice

This repository contains my hands-on SQL practice focused on understanding JOINs and basic aggregation.

I built this while learning step-by-step, starting from simple table creation to more advanced queries using COUNT, SUM, GROUP BY, and HAVING.

## What I practiced
- Creating tables with relationships
- LEFT JOIN and RIGHT JOIN
- Finding missing data using NULL
- Counting records per group
- Summing values per group
- Filtering grouped data using HAVING

## Key understanding
LEFT JOIN helps to keep all records from the main table even if there is no match in the second table.

GROUP BY helps to form groups, and aggregate functions like COUNT and SUM operate on those groups.
